# Guide rapide pour les agents IA

- **Projet** : portfolio de Fiona Talbi en français, React 19, TanStack Start, Vite et TypeScript. Le dépôt est lié à Lovable : ne réécrivez pas l'historique publié de `main`.
- **Structure** : `src/data/portfolio.ts` centralise le contenu et les métadonnées. `src/components/portfolio.tsx` assemble les sections de `src/components/portfolio/` ; `src/styles.css` gère l'apparence. Les hooks `use-portfolio-navigation` et `use-reveal` gèrent la navigation et les animations. Les routes sont dans `src/routes/` ; ne modifiez pas `src/routeTree.gen.ts` à la main.
- **Modifier le contenu** : éditez les objets typés de `src/data/portfolio.ts`, conservez leurs identifiants stables et utilisez des métriques `{ id, value, label }`. Gardez les faits séparés des composants ; n’inventez pas de dates, diplômes, disponibilité, photo ou CV. Les lettres restent `pending` avec `documentPath: null` jusqu’à réception des vrais PDF. Placez ensuite les documents dans `public/`, renseignez leur chemin relatif et passez leur statut à `available` : les cartes et le lien du menu réapparaîtront automatiquement.
- **Développement** : Node.js 24 et Bun 1.4.3. `bun install --frozen-lockfile`, puis `bun run dev`. Avant livraison : `bun run test`, `bun run lint`, `./node_modules/.bin/tsc --noEmit`, `bun run build` et `GITHUB_PAGES=true bun run build`. Le lint conserve quelques avertissements React Refresh dans les composants UI.
- **Design** : polices locales, contenu lisible sans JavaScript et animations compatibles avec `prefers-reduced-motion`. Préservez « Contact » visible sur mobile, les cibles de 44 px minimum et les résultats avant la photo. Réservez les flèches diagonales aux vrais liens externes. Préservez les ancres, les contrastes et les interactions au clavier.
- **Publication** : `.github/workflows/pages.yml` publie automatiquement chaque push sur `main` sur GitHub Pages : <https://fio-tlb.github.io/fiona-talbi-portfolio/>. Le build Pages précompile la page `/` dans `dist/client` avec le préfixe `/fiona-talbi-portfolio/`.
- **Contraintes Pages** : utilisez `import.meta.env.BASE_URL` pour les fichiers de `public/`. Pages ne fournit pas de serveur applicatif : les fonctionnalités doivent fonctionner dans le navigateur ou être précompilées.
